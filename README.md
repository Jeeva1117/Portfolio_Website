1. **01. Self-Healing RAG Agent *(Flagship)***
   - **Domain**: Generative AI · Agentic AI
   - **Stack**: Python, LangGraph, LangChain, Groq LLM, RAG, Hybrid Search, Reranking, FastAPI, React, PostgreSQL
   - **Description**: An intelligent self-healing Retrieval-Augmented Generation system that automatically detects retrieval failures, evaluates response quality, and improves answers through multi-agent workflows.

2. **02. AI Speech-to-Sign Language Translator**
   - **Domain**: Deep Learning · NLP · Computer Vision
   - **Stack**: Python, Deep Learning, NLP, Speech Recognition, WLASL, Transformers, Computer Vision, 3D Avatar Animation
   - **Description**: A real-time AI application that converts spoken language into sign-language sequences and generates corresponding 3D avatar animations to improve communication accessibility.

3. **03. AI Data Analyst Agent**
   - **Domain**: Agentic AI · Data Science
   - **Stack**: Python, LangGraph, LLMs, Pandas, NumPy, Scikit-learn, Text-to-SQL, FastAPI, PostgreSQL
   - **Description**: An intelligent AI data analyst that processes datasets, understands natural-language questions, performs automated analysis, generates visualizations, and delivers actionable business insights.

4. **04. TubeNext – AI-Powered YouTube Analytics**
   - **Domain**: AI Analytics · Machine Learning
   - **Stack**: Python, Machine Learning, Data Analytics, YouTube Data API, LLMs, Data Visualization
   - **Description**: An AI-powered YouTube analytics platform that evaluates channel performance, analyzes video metrics, identifies growth opportunities, and provides intelligent recommendations for content creators.

5. **05. AgroNext – AI-Powered Plant Disease Detection & Voice Assistant**
   - **Domain**: AI · Machine Learning · Voice AI
   - **Stack**: Python, Machine Learning, Deep Learning, CNN, Computer Vision, Image Classification, Speech Recognition, Text-to-Speech, NLP, FastAPI
   - **Description**: An intelligent agricultural AI assistant that detects plant diseases from leaf images, identifies potential infections, and provides relevant treatment recommendations. It also allows farmers to interact through voice.
